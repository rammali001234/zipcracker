<p align="center">
  <b>ZipCracker</b> is a Python-based ZIP password recovery tool that tests passwords from a user-provided wordlist against encrypted ZIP archives.
</p>

---

✨ Features

· ⚡ Fast wordlist-based password testing
· 🖥️ Simple command-line interface
· 🪶 Lightweight and easy to use
· 📂 Supports custom wordlists
· 📊 Progress display during testing
· 🔧 Open-source and customizable

---

🚀 Installation & Usage

1. Clone the Repository

git clone https://github.com/rammali001234/zipcracker.git
cd zipcracker

2. Run the Tool

python3 zipcracker.py <zip_file> -w <wordlist>

Example:

python3 zipcracker.py secret.zip -w wordlist.txt

3. Interactive Mode (Without Wordlist)

python3 zipcracker.py secret.zip

---

📋 Requirements

· Python 3.x
· No external libraries needed (uses built-in zipfile module)
